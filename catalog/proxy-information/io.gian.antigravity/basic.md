# Antigravity: basic information review

The basic-information body has three fixed lines. The following notes are for review, not extra UI fields.

## Display order and source

| Order | Field | Where the value comes from |
| --- | --- | --- |
| 1 | Runtime path | The Host's external Runtime discovery and verification result |
| 2 | Runtime version | The checked current Runtime version; do not substitute latest for a missing installation |
| 3 | Proxy version | The active Proxy or an explicitly labeled development source; otherwise not installed |

The name and icon stay in the title. Installation actions and progress follow the three lines. Antigravity has no Gian-managed or Custom HOME controls; catalog queries use the OS account's HOME.

## Current release-target snapshot

The current certified release target is Proxy **0.0.5** with Runtime **1.4.3**. This is a published target, not this machine's installation state.
