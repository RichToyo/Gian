# Grok Build: basic information review

Basic information shows the Runtime path, the Runtime version, and the Proxy version. The current release target is Proxy **0.3.7** and Grok CLI **1.0.41**. That does not mean the user's machine has finished install or sign-in.

Target location:

```text
<dataDir>/runtimes/grok/1.0.41/<artifact-sha256>/bin/grok
```

Agent HOME, account state, and native sessions are not part of the signed Catalog, and they are not inherited automatically from another `~/.grok`.
